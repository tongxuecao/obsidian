### 📝 Java `static` 静态变量笔记

#### 1. 什么是静态变量？

- **定义**：被 `static` 关键字修饰的成员变量，被称为**静态变量**（或类变量）。
    
- **归属**：静态变量不属于某个具体的对象，而是**属于整个类**。
    
- **核心优势**：**节省内存**。无论创建多少个对象，静态变量在内存中永远**只有一份**，被所有该类的对象所共享。
    

#### 2. 静态变量的存储位置与生命周期

##### 存储位置

- **内存划分**：**JDK 8 及之后**，静态变量存储在堆内存（Heap）当中（准确地说是随 Class 对象一起存放在堆中）。
    

> _注：在 JDK 7 及以前，静态变量存储在方法区的永久代（PermGen）中。_

##### 初始化时机

- **开辟空间与初始化**：在类加载（Class Loading）阶段时初始化并开辟空间。
    
- **与对象的关系**：静态变量的生命周期远早于对象的创建。在**任何对象生成之前**，静态变量就已经存在于内存中了。
    

在一个类中，当一个实例变量的一直不变时，例如籍贯都为中国，直接加static作为静态实例变量，节省空间。
#### 3. 静态变量的访问方式

```
// 正确且推荐的方式
类名.静态变量名;

// 可以访问但不推荐的方式
实例变量名.静态变量名;
```

##### 注意事项

- **强烈建议一律采用类名访问**


### 💡 总结对比表

|**特性**|**实例变量（无 static）**|**静态变量（有 static）**|
|---|---|---|
|**所属**|属于单个**对象**（实例）|属于整个**类**|
|**内存位置**|堆内存（每个对象内部）|堆内存（随 Class 对象存放）|
|**生命周期**|`new` 对象时创建，对象被 GC 回收时销毁|**类加载时**创建，类卸载时销毁（生命周期长）|
|**访问方式**|必须 `new` 对象，通过 `对象名.` 访问|直接通过 `类名.` 访问（推荐）|
|**数量**|每创建一个对象，就多一份|无论创建多少对象，**内存中仅此一份**|
