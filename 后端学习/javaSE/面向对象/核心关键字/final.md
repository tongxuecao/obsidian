### Java `final` 关键字笔记

#### 概念：**最终的、不可变的**

#### 一、 三个“不可变”（核心应用）

1. **类不可变**：修饰类时，该类**不能被继承**（如 `String` 类）。
    
2. **方法不可变**：修饰方法时，该方法**不能被子类重写（覆盖）**。
    
3. **变量不可变**：修饰变量时，一旦赋值，**不能重新赋值**（变为常量）。
    

#### 二、 两个重要细节

1. **实例变量赋值时机**： `final` 修饰的成员变量没有默认初始值，**必须在构造方法执行结束前手动完成赋值**。
    
2. **引用类型的“变与不变”**：
    
    - **地址不可变**：`final` 修饰引用对象时，不能再指向其他新对象。
        
    - **数据可变**：但该对象**内部的属性/数据依然是可以修改的**。
        

#### 三、 黄金搭档（常量定义）

- **`static final`**：联合使用修饰实例变量，即为 Java 中的**全局常量**（命名规范要求全大写，单词间用下划线隔开）。
