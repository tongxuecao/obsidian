### 一、 核心概念与价值

1. **是什么**：子类继承父类的属性和方法（通过 `extends` 关键字），子类是对父类的**扩展（Extension）**。
    
2. **为什么用**：
    
    - **代码复用**：抽取共性到父类，减少重复代码（如 `BaseEntity`）。
        
    - **多态基石**：没有继承和方法重写，就无法实现多态（面向对象的核心）。
        

### 二、 语法与三大特征

1. **单继承性**：Java 类**只支持单继承**（一个类只能有一个直接父类），不支持多继承（避免菱形继承冲突）。
    
2. **多层继承**：支持祖孙三代结构（A -> B -> C），C 间接继承 A。
    
3. **顶层老祖宗**：所有 Java 类（除 Object 本身）都直接或间接继承自 `java.lang.Object`。
    

### 三、 子类能做什么（四大能力）

- **继承（用）**：自动拥有父类所有非 `private` 的属性和方法。
    
- **扩展（加）**：定义子类特有的新属性和新方法。
    
- **改造（改）**：**方法重写（Override）**，保持方法签名不变，重写业务逻辑。
    
- **重构（引）**：在构造方法第一行通过 `super()` 调用父类构造，完成父类属性的初始化。
    

### 四、 避坑指南（底线红线）

1. **构造方法不能被继承**（类名不同），只能通过 `super` 关键字调用。
    
2. **私有成员（`private`）不能直接访问**，必须通过父类提供的 `public` 方法（如 getter/setter）间接访问。
    
3. **方法重写权限不能缩小**：子类重写的方法，访问权限必须 $\ge$ 父类方法权限（如父类是 `public`，子类绝不能是 `private`）。
    

### 🛠 高级思考（架构原则）

- **组合优于继承（Favor composition over inheritance）**：
    
    - **继承（is-a）**：强耦合，子类对父类底层透明（白盒复用）。只能在确有逻辑隶属关系时使用。
        
    - **组合（has-a）**：低耦合，黑盒复用，系统更灵活。实际开发中优先考虑组合。


### 方法覆盖
* 方法覆盖/override/方法重写/overwrite
* 1. 什么时候考虑使用方法重写？
*      当从父类中继承过来的方法，无法满足子类的业务需求时。
* 
* 2. 当满足什么条件的时候，构成方法重写？
*      条件1：方法覆盖发生在具有继承关系的父子类之间。
*      条件2：具有相同的方法名
*      条件3：具有相同的形参列表
*      条件4：具有相同的返回值类型
* 
* 3. 关于方法覆盖的细节：
*      3.1 当子类将父类方法覆盖之后，将来子类对象调用方法的时候，一定会执行重写之后的方法。
*      3.2 在java语言中，有一个注解，这个注解可以在编译阶段检查这个方法是否是重写了父类的方法。
*          @Override注解是JDK5引入，用来标注方法，被标注的方法必须是重写父类的方法，如果不是重写的方法，编译器会报错。
*          @Override注解只在编译阶段有用，和运行期无关。
*      3.3 如果返回值类型是引用数据类型，那么这个返回值类型可以是原类型的子类型

| **特征**     | **方法重载 (Overload)**                                                  | **方法重写 (Override)**                    |
| ---------- | -------------------------------------------------------------------- | -------------------------------------- |
| **发生范围**   | **同一个类**中                                                            | **父子类**之间（具有继承关系）                      |
| **方法名**    | **必须相同**                                                             | **必须相同**                               |
| **形参列表**   | **必须不同**（个数、类型、顺序）                                                   | **必须相同**                               |
| **返回值类型**  | **完全无关**                                                             | **必须相同**（或是其子类）                        |
| **典型应用场景** | 同样的功能，但支持传入不同的参数（如 `System.out.println()` 可以传 int, String, double 等） | 子类不满足父类的业务逻辑，需要重新实现（如猫和狗重写哺乳动物的“叫声”方法） |
