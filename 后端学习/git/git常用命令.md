## 一、基础目录操作命令

### 1. cd（change directory 切换目录）
功能：切换当前工作文件夹

- `cd 目录名`：进入指定目录，示例：`cd src`
- `cd ..`：返回上一级目录
- `cd`（无参数）：回到当前用户家目录

### 2. pwd（print working directory 打印工作目录）

功能：输出当前所在文件夹完整绝对路径

### 3. ls /ll（list 列出文件）

- `ls`：简洁展示目录内文件、文件夹名称
- `ll` = `ls -l`：详细展示，包含权限、所有者、文件大小、修改时间、文件名

### 4. mkdir（make directory 创建目录 / 文件夹）

功能：新建文件夹

- 基础用法：`mkdir src`，创建 src 文件夹
- 拓展参数：`mkdir -p a/b/c`，一次性创建多级嵌套文件夹

### 5. rmdir（remove directory）

功能：仅删除**空文件夹**

## 二、文件增删改操作命令

### 1. touch

功能：创建空白文件；文件已存在时仅更新文件修改时间

示例：`touch index.js`，生成空白 index.js 文件

### 2. rm（remove 删除）

功能：永久删除文件（Linux 无回收站，删除不可恢复）

- 删除文件：`rm index.js`
- 删除文件夹：`rm -r src`
    
    - `-r`=recursive 递归删除，会删掉文件夹内全部内容
    - ⚠️高危警告：禁止执行`rm -rf /`，会清空系统全部文件
    
### 3. mv（move）

两种用法：

1. 移动文件：`mv index.html src`，将文件移入同级 src 文件夹
2. 重命名文件：同目录执行`mv old.js new.js`实现改名
    
    PPT 问题：原描述残缺，mv 兼具移动、重命名两种能力

### 补充：cp（copy）

功能：复制文件 / 文件夹

## 三、终端辅助命令

### 1. clear

简易清屏，仅隐藏历史输出，向上滚动仍可查看旧内容，日常使用首选

### 2. reset

彻底重置终端会话，清空全部输出、重置光标，清理力度大于 clear

### 3. history

功能：列出当前终端所有输入过的命令，每条自带编号

快捷操作：`!编号`，快速重新执行对应历史命令

### 4. help

- 作用：查看 shell 内置命令说明文档
- 外部程序查看帮助格式：`命令 --help`，示例`ls --help`

### 5. exit

关闭当前终端窗口；SSH 远程连接服务器时执行会断开远程连接

## 四、脚本 / 命令注释符号

`#` 为注释标记，写在命令行或 shell 脚本中，# 后方内容系统不会执行，仅用于文字备注
