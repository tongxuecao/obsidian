## 1. 数据读取函数

在后端或数据开发初期，将外部文件转化为 Pandas 对象的基础武器：

- **`pd.read_csv()`**：读取 CSV 或以特定分隔符（如 `\t`）分隔的文本文件。常用参数包括 `sep`（指定分隔符）、`encoding`（处理编码报错，如 `gbk`）和 `chunksize`（应对大文件内存溢出的分块读取）。
    
- **`pd.read_excel()`**：读取 Excel 文件（.xlsx/.xls）。支持 `sheet_name` 指定工作表，以及通过 `header=[0, 1]` 处理**双层/多层复杂嵌套表头（MultiIndex）**，通过 `index_col=0` 将特定列设为行索引 。
    
- **`pd.read_json()`**：读取扁平化的 JSON 数组并直接转化为 DataFrame。
    

## 2. 基础信息与描述性统计函数

用于快速了解数据整体面貌和进行数学计算：

- **`df['列名']` 与 `df[['列名1', '列名2']]`**：
    
    - 单括号 `[]` 传入字符串提取单列，返回 **Series**。
        
    - 双括号 `[[]]` 嵌套传入列表提取一列或多列，返回 **DataFrame**（保持二维表格结构）。
        
- **`.mean()`、`.sum()`、`.std()`、`.var()`、`.max()`、`.min()`**：用于计算均值、求和、标准差、方差、最大值和最小值 。可直接作用于整个 DataFrame、特定列，或紧跟在 `groupby` 后面作为聚合函数 。
    
- **`.copy()`**：显式复制一份独立的 DataFrame 副本。当对切片或选列出来的子集进行修改或排序时，**加上 `.copy()` 可以彻底规避 `SettingWithCopyWarning` 警告**。
    

## 3. 数据分组与聚合函数（核心）

类似于 SQL 中的 `GROUP BY` 思想，用于分门别类地进行统计分析 ：

- **`.groupby()`**：**核心拆分函数**。通过 `by` 参数指定分组依据（可以是列名、列名列表或外部 Series）。
    
    - **懒加载特性**：直接调用时返回的是一个临时的 `GroupBy` 中间对象，需要配合聚合函数才会爆发计算。
        
    - **核心参数**：`as_index=False`（防止分组键变成行索引，让输出结果像 SQL 结果一样规整）、`sort=False`（在大数据量且不在乎顺序时，关闭自动排序以提升运行性能）。
        
- **`.value_counts()`**：专门用于统计某一列中各个唯一值出现的**频数（数量）**，默认按数量从高到低降序排列 。
    

## 4. 排序与去重函数

在做数据清洗和特征工程时，保证数据有序性和唯一性的核心操作：

- **`.sort_values()`**：**DataFrame 和 Series 排序的标准方法**。
    
    - **整行联动**：对 DataFrame 的某列或多列排序时，整行数据会跟着联动，绝不发生数据错位。
        
    - **多列排序**：支持传入列表实现有先后主次顺序的复合排序，如 `by=['A', 'B'], ascending=[True, False]`（先按 A 升序，A 相同再按 B 降序）。
        
- **`.sort_index()`**：对表格或 Series 的**行索引**进行重新排序（如将 `value_counts()` 统计后的乱序索引拉回从小到大的正序）。
    
- **`.drop_duplicates()`**：**DataFrame（多列表格）去重的专用方法**。支持 `keep='first'/'last'/False` 控制重复行的留存策略，支持 `subset` 选定特定列进行局部去重。
    
- **`.unique()`**：**仅属于 Series（单列）的去重方法**。返回一个无序的 NumPy 数组，主要用于快速查看该列包含了哪些不重复的唯一值 。
    

## 💡 Python 内置函数对比提醒

- **`sorted()`**：Python 内置的全局排序函数。可以接收 Pandas 去重后的数组（如 `sorted(df['quality'].unique())`）并返回一个排好序的 **Python 原生列表**，但**绝不能**直接用于 DataFrame 的整表列排序，否则会导致严重的数据错位。
