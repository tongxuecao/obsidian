### 🚀 黑马 Java 教程（上下部）定制观看计划

建议你将这套动辄几百集的课程，**压缩在 5-7 天内刷完**。

#### ❌ 第一部分：直接跳过（坚决不看，节省 40% 时间）

这些内容与 C++ 高度重合，你的算法底子足够你直接在写代码时靠肌肉记忆或查文档解决。

- **基础语法**：变量类型、运算符、`if/switch`、`for/while` 循环、一维/二维数组。
    
- **基础算法**：冒泡排序、二分查找（这些你在蓝桥杯已经写烂了）。
    
- **老旧技术（如果有带到）**：GUI 图形化界面（Swing/AWT）、XML 基础解析。
    

#### ⏩ 第二部分：光速略过（开启 1.5 - 2.0 倍速，知道语法即可）

这些是 Java 面向对象的基础，思想与 C++ 类似，但语法有差异。

- **类与对象、封装、继承、多态**：重点听 Java 是**单继承、多实现**（区别于 C++ 的多继承），了解 `super` 和 `this` 的用法。
    
- **抽象类与接口（Interface）**：快速过一下语法。Java 后端是“面向接口编程”的天下，知道 `implements` 怎么写就行。
    
- **异常处理（Exception）**：了解 `try-catch-finally` 的执行顺序，以及自定义异常的写法。
    
- **常用 API**：`String`、`StringBuilder`、`Date` 等工具类，当字典看，知道有这些东西就行，用的时候再查。
    

#### 🎯 第三部分：重点深挖（正常语速，必须手敲代码，耗时核心）

这部分是 Java 的灵魂，也是你后续学习 Spring 框架和后端工程化的基石。**（集中在下部视频）**

1. **集合框架（Collections）—— 对应 C++ STL**
    
    - **重点看**：`ArrayList`、`LinkedList`、`HashMap`、`HashSet`。
        
    - **必须搞懂**：`HashMap` 的底层原理（黑马老师讲得非常细，数组+链表+红黑树），这是面试必考题。了解 Java 集合的遍历方式（迭代器 `Iterator` 和增强 `for`）。
        
2. **泛型（Generics）**
    
    - **重点看**：Java 泛型机制与 C++ 模板完全不同！重点听老师讲“泛型擦除”以及通配符 `? extends` 和 `? super`，这里非常容易踩坑。
        
3. **反射（Reflection）与 注解（Annotation）—— 框架的灵魂！**
    
    - **重点看**：**这里是重中之重！** C++ 没有原生的反射。你必须跟着视频敲一遍：如何在运行时获取类的构造方法、成员变量和方法，并动态执行它。不搞懂反射和自定义注解，你后面学 Spring 会像听天书一样。
        
4. **多线程（JUC 基础）**
    
    - **重点看**：线程的创建方式（`Runnable`, `Callable`）、线程同步机制（`synchronized` 关键字、`Lock` 锁）。了解一下线程池（`ThreadPoolExecutor`）的概念。
        
5. **Java 8 新特性（Lambda & Stream）**
    
    - **重点看**：利用你的算法底子，重点学习 Stream 流操作。它能让你用一行代码完成 C++ 里十几行的集合过滤、映射和收集操作，后端开发天天都在用。
        
6. **IO 流（可选/速通）**
    
    - 只需快速了解字节流和字符流的区别，看看如何读写文件。现代后端开发直接操作底层流的场景较少，多用第三方库替代。

### 💡 给你的额外建议：避免“教程地狱”

1. **不要背 API**：看集合和字符串操作时，不要去背 `indexOf`、`substring` 这些方法的参数。知道有这个功能，写代码时靠 IDEA 的代码提示或百度就行。
    
2. **IDE 快捷键**：在看视频的第一天，先熟练掌握 IntelliJ IDEA 的快捷键（如 `sout`、`psvm`、`Alt+Enter` 导包、`Ctrl+Alt+V` 自动生成变量）。这会让你写 Java 爽感翻倍。
